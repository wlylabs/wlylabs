## 🚀 About Me

I'm an independent **solo builder** who turns ideas into shipped products — fast.

I work the **vibe coding** way: intuition-driven design, tight iteration loops, and
AI doing the heavy lifting — so my time goes into *what* to build instead of *how*
to type it out.

No team. No bureaucracy. No standups. Just an idea, a terminal, and a clean commit history.
